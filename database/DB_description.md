## Общая информация
База данных выполнена на SQLite. В ней хранятся данные о пользователях, упражнениях, шаблонах тренировок, проведённых тренировках, истории веса. Схема обеспечивает целостность данных с помощью внешних ключей и индексов.

## Перечень таблиц

### 1. `users` – пользователи приложения
Хранит учётные записи и данные для расчёта стрика (серии тренировок).

| Поле | Тип данных | Ограничения | Описание |
|------|-----|-------------|----------|
| `id` | INTEGER | PRIMARY KEY | Уникальный идентификатор пользователя |
| `username` | TEXT | UNIQUE NOT NULL | Логин пользователя |
| `password_hash` | TEXT | NOT NULL | Хеш пароля |
| `name` | TEXT | | Имя пользователя (необязательно) |
| `created_date` | TEXT | NOT NULL DEFAULT (datetime('now')) | Дата регистрации (в формате YYYY-MM-DD) |
| `current_streak` | INTEGER | NOT NULL DEFAULT 0 | Текущая серия дней подряд с выполненными тренировками |
| `last_workout_date` | TEXT | | Дата последней выполненной тренировки (для расчёта стрика) |

---

### 2. `exercises` – справочник упражнений
Содержит названия и описания упражнений, доступных для добавления в шаблоны и тренировки.

| Поле | Тип данных | Ограничения | Описание |
|------|-----|-------------|----------|
| `id` | INTEGER | PRIMARY KEY | Уникальный идентификатор упражнения |
| `name` | TEXT | NOT NULL | Название упражнения |
| `description` | TEXT | | Краткое описание или техника выполнения |
| `muscle_group` | TEXT | | Целевая группа мышц |

---

### 3. `workout_templates` – шаблоны тренировок
Позволяют создавать готовые программы тренировок. Могут быть общими (is_public = 1) или личными (принадлежат конкретному пользователю).

| Поле | Тип данных | Ограничения | Описание |
|------|-----|-------------|----------|
| `id` | INTEGER | PRIMARY KEY | Уникальный идентификатор шаблона |
| `user_id` | INTEGER | FOREIGN KEY (users.id) ON DELETE CASCADE | Ссылка на владельца шаблона (NULL для общедоступных) |
| `name` | TEXT | NOT NULL | Название шаблона |
| `description` | TEXT | | Подробное описание шаблона |
| `category` | TEXT | | Тип тренировки: силовая, кардио, растяжка и т.п. |
| `is_public` | INTEGER | NOT NULL DEFAULT 0 | 1 – шаблон доступен всем, 0 – только владельцу |

---

### 4. `template_exercises` – упражнения в шаблонах
Связующая таблица между шаблонами и упражнениями. Задаёт порядок, подходы, повторения и вес по умолчанию.

| Поле | Тип данных | Ограничения | Описание |
|------|-----|-------------|----------|
| `id` | INTEGER | PRIMARY KEY | Уникальный идентификатор записи |
| `template_id` | INTEGER | NOT NULL FOREIGN KEY (workout_templates.id) ON DELETE CASCADE | Ссылка на шаблон |
| `exercise_id` | INTEGER | NOT NULL FOREIGN KEY (exercises.id) ON DELETE CASCADE | Ссылка на упражнение |
| `sets` | INTEGER | | Количество подходов (по умолчанию) |
| `reps` | INTEGER | | Количество повторений (по умолчанию) |
| `weight` | REAL | | Вес в кг (по умолчанию) |
| `order_index` | INTEGER | NOT NULL | Порядковый номер упражнения в рамках шаблона (для сортировки) |

---

### 5. `workout_sessions` – тренировочные сессии
Фиксирует каждую тренировку пользователя (как запланированную, так и выполненную).

| Поле | Тип данных | Ограничения | Описание |
|------|-----|-------------|----------|
| `id` | INTEGER | PRIMARY KEY | Уникальный идентификатор сессии |
| `user_id` | INTEGER | NOT NULL FOREIGN KEY (users.id) ON DELETE CASCADE | Ссылка на пользователя |
| `template_id` | INTEGER | FOREIGN KEY (workout_templates.id) ON DELETE SET NULL | Ссылка на шаблон, если сессия создана на его основе |
| `name` | TEXT | | Название тренировки (если создана без шаблона) |
| `date` | TEXT | NOT NULL | Дата и время тренировки (в формате YYYY-MM-DD) |
| `times` | INTEGER | | Длительность в минутах |
| `notes` | TEXT | | Заметки |
| `status` | TEXT | NOT NULL CHECK (status IN ('planned','completed')) | Статус: запланирована или выполнена |

---

### 6. `session_exercises` – выполненные упражнения в конкретной сессии
Содержит фактические данные по каждому упражнению, выполненному во время тренировки.

| Поле | Тип данных | Ограничения | Описание |
|------|-----|-------------|----------|
| `id` | INTEGER | PRIMARY KEY | Уникальный идентификатор записи |
| `session_id` | INTEGER | NOT NULL FOREIGN KEY (workout_sessions.id) ON DELETE CASCADE | Ссылка на сессию |
| `exercise_id` | INTEGER | FOREIGN KEY (exercises.id) ON DELETE SET NULL | Ссылка на упражнение (может быть NULL, если упражнение удалено из справочника) |
| `sets` | INTEGER | | Фактическое количество подходов |
| `reps` | INTEGER | | Фактическое количество повторений |
| `weight` | REAL | | Фактический использованный вес |
| `notes` | TEXT | | Заметки по конкретному упражнению |

---

### 7. `weight_log` – история веса пользователя
Позволяет отслеживать изменения веса тела.

| Поле | Тип данных | Ограничения | Описание |
|------|-----|-------------|----------|
| `id` | INTEGER | PRIMARY KEY | Уникальный идентификатор записи |
| `user_id` | INTEGER | NOT NULL FOREIGN KEY (users.id) ON DELETE CASCADE | Ссылка на пользователя |
| `date` | TEXT | NOT NULL | Дата измерения (в формате YYYY-MM-DD) |
| `weight` | REAL | NOT NULL | Вес в килограммах |
