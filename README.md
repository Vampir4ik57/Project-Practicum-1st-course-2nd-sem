# GYMBRO — Интерактивный планировщик тренировок

**GYMBRO** — это полноценный веб-сервис для спортсменов, позволяющий планировать тренировки, вести дневник прогресса, отслеживать изменения массы тела и поддерживать мотивацию с помощью системы «стриков» (непрерывных серий тренировок).

Проект разработан в рамках дисциплины **«Проектный практикум» (1 курс, 2 семестр)**.

## Ключевой функционал
*  **Безопасность:** Регистрация и авторизация пользователей с безопасным хешированием паролей (bcrypt) и сессионными куками.
*  **Умный календарь:** Планирование тренировок с защитой от изменения статусов выполненных занятий или планирования «в прошлое».
*  **Каталог шаблонов:** Разделение программ на «Мои шаблоны» (приватные), «Библиотеку» (системные) и «Сообщество» (публичные шаблоны других пользователей).
*  **Снапшоты истории:** При завершении тренировки создается независимый «слепок» данных. История пользователя не искажается даже при полном удалении исходных шаблонов из базы.
*  **Аналитика:** Интерактивный график изменения массы тела в профиле пользователя.
*  **Геймификация:** Автоматический расчет текущей серии тренировок (streak) на основе выполнения настраиваемой еженедельной цели.
*  **Обратная связь:** Встроенная система отправки отзывов напрямую в базу данных.

## Технологический стек

* **Бэкенд:** Python 3, FastAPI, Uvicorn
* **База данных:** SQLite3 (с поддержкой FOREIGN KEY и оптимизацией запросов через индексы)
* **Фронтенд:** HTML5 (Jinja2 Templates), CSS3
* **Валидация:** Pydantic v2 & FastAPI Form validation

## Инструкция по локальному запуску
1. Клонирование репозитория:
* git clone [https://github.com/ВАШ_ЛОГИН/Project-Practicum-1st-course-2nd-sem.git](https://github.com/ВАШ_ЛОГИН/Project-Practicum-1st-course-2nd-sem.git)
* cd Project-Practicum-1st-course-2nd-sem
2. Создание и активация виртуального окружения:
**Для Windows:**
* python -m venv venv
* venv\Scripts\activate

**Для macOS / Linux:**
* python3 -m venv venv
* source venv/bin/activate

3. Установка зависимостей:
* pip install -r requirements.txt

4. Запуск сервера:
* Выполните команду из корневой папки проекта:
* uvicorn backend.main:app --reload

5. После запуска приложение будет доступно по адресам:
 * Веб-интерфейс: http://127.0.0.1:8000
 * API Документация (Swagger UI): http://127.0.0.1:8000/docs
